# WhatsApp Message Flow Simulation

This Python script simulates the basic flow of sending a WhatsApp message. It demonstrates the client-server model, message encryption (simplified), and delivery to a recipient.

## Language

`python`

## How to Run

Save the code as `whatsapp_flow.py` and run it from your terminal using `python whatsapp_flow.py`.
